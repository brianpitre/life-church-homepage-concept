# The Life Church — Homepage Concept

A working first-pass concept for a new thelifechurch.com homepage. It is a design study, not the live site.

The page keeps Memphis time. The headline, colors and countdown change through the week, and the dated
content (latest message, Instagram, events) ages and drops off on its own. The "Time machine" pill in the
corner is a demo control for stepping through those states; it is not part of the design.

```
index.html   the page: one self-contained file, CSS and JS inlined
media/       photos and video the page uses (copies of files on thelifechurch.com)
robots.txt   the same file as the other share pages
```

This folder is generated. The source is `homepage-concept/index.html` in the working project, and
`tools/build_artifact.py pages` rebuilds this copy from it, so edit the source and rebuild.

Photography, video and copy belong to The Life Church.
